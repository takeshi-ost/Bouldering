# ASCENT

胴体をスワイプし、四肢のうち2点を固定して残り2肢を動かすクライミングパズルです。

## 起動

[index.html](index.html) をブラウザで開き、「ノーマルコース」または「ロジハラコース」を選ぶとスゴロク状のステージマップが開きます。レベルのコマをタッチするとプレイを開始します。選択画面の「くわしい説明」から操作やホールドのルールを確認できます。ビルド・インストールは不要です。ゴール側から一定速度で最下段へスクロールし、中央にSTAGE番号を表示し、最下段への到着と最低1秒の表示を満たすと操作可能になります。1画面のステージでも1秒表示します。

- クリアすると次のレベルを解放し、結果画面の「次のステージへ」からマップへ戻るとコマが1つ進みます。クリア済みレベルも選び直せます。MAPで現在の挑戦を終了してマップへ戻れます。進行はコース別に端末へ保存します（保存できない環境では、そのセッション中のみ維持します）。
- 全ステージ、最下段の2個のホールドに両足、上方の横長ホールド1個に両手を置いて開始します。足幅は140px以内に収め、開始時だけ4接触を保って胴体をできるだけ低く構えます。開始用3ホールドで囲む三角形内は通常ホールドの配置を避けます。
- ステージは最大3画面。2画面以上の長いステージは5ステージごとに登場します。
- フィールドの任意の位置からスワイプして移動します。
- 支持ペアは6組を内部評価し、開始方向への移動先が多い組、同条件なら移動距離が長い組を選びます。
- スワイプ中は2点を固定し、残り2肢の吸着先はリアルタイムに変化します。
- 足先の上限はボディ中点です。股関節より高い足は膝の内角150度以上（ほぼ直線）で届く場合だけ許可します。固定足を支点に動く途中も判定し、両コースの生成・再生で検証します。
- 四肢の骨は固定長です。関節と胴体を「足先より低い膝の数 → 全違反数 → 共通コスト」の順で評価します。膝の高さは股関節基準から足先基準へ置き換えました。近い手では肘を低く保つことより外向きを優先する場合があります。手足はボディの奥に描きます。 四肢固定後は同じ評価式で描画上の胴体位置も調整し、4つの接触を保てる移動経路で姿勢が改善する場合に移動します。
- 全四肢が吸着していれば移動を確定でき、1手消費します。同じ4接触位置への復帰やキャンセルは消費しません。
- プレイヤーのボディは押している間だけ3px沈んで色が変わり、短くタップすると直前の確定移動を1回取り消し、姿勢・手数・スタミナを戻せます。新しい移動後は再び利用でき、クリア・手数切れ直後にも使えます。
- 横幅2倍のホールドは両手、または両足で共有できます（手足混在は不可）。両コースとも開始用1個＋途中0〜2個を配置します。
- 両手でゴールを掴むとクリア。開始スタミナは「想定手数＋想定手数÷10の切り捨て−❤️個数×2」です。❤️なしなら10手で11、20手で22、30手で33になります。クリア時の残量は次ステージへ持ち越しません。
- ステージ5以降、想定5手以上のルートに❤️を0〜2個配置します。1個なら前半、2個なら1個目を1/3・2個目を2/3までに置き、回復がゴール直前に偏るのを防ぎます。ボディが触れるだけでスタミナが2回復し、取得位置に「+2」が1秒で30px上昇しながら消えます。4肢が吸着していない姿勢でも取得できます。キャンセル・Undoでも取得と回復分は維持し、同じ❤️の重複取得はできません。RETRY／RESTARTでは開始状態に戻します。
- レベル20以降は青く小さいギザギザのホールドを0〜5個追加します。新たに保持して移動を確定すると、通常の1手に加えて1個につきスタミナを1消費します。同じ四肢での保持継続は追加消費せず、持ち替え・離した後の再保持では毎回追加消費します。キャンセルは無料、Undoは消費分も戻します。ルート付近や近道になりそうな位置へ置き、使わないクリアルートを維持します。
- ステージを2本指で上下にスワイプするとスクロールできます。PCではホイール、またはステージにフォーカスして方向キー等でスクロールできます。
- 「パス表示」で想定ルートを表示します。クリア後はチェックの状態にかかわらず、実際の確定位置を結ぶルートを自動表示します。

## コースの比較

- **ノーマルコース**：従来の生成・密度調整・ルート検証・削減処理をそのまま使用します。
- **ロジハラコース**：同じレベルの初期ガイドパス・開始位置・ゴール・壁高を共有します。ガイド沿いに不均等な間隔と位置の揺らぎを持つ手足の候補だけを置き、実操作と同じルールで解法を求めます。壁全体への追加や密度調整は使いません。
- 試作では求めた胴体ルートを固定し、通常ホールドを1個ずつ仮削除して全手を再生します。支点や接触先が変わっても通過できれば削除し、削除できなくなるまで繰り返します。残った通常ホールドはどれも、このルートの再生に必要です。全組み合わせでの最少個数を保証するものではありません。
- 初期ガイドを共有しますが、探索後の手順・ホールド・手数はコースごとに異なります。触れないホールドも支持ペア選択に必要な場合は残します。
- マップの「コース選択」でコースを選び直せます。コースごとにクリア状況を維持し、RETRY／RESTARTは選択したレベルをやり直します。

## 実装構成

| ファイル | 役割 |
| --- | --- |
| `js/config.js` | 可動域・配置・表示の設定 |
| `js/utils.js` | 座標計算とシード付き乱数 |
| `js/stage.js` | 初期ホールド、折れ線ガイド、密度調整 |
| `js/game.js` | 2肢固定、吸着、確定、勝敗、開始演出 |
| `js/route.js` | 2肢固定の探索・再生・ホールド削減・最終生成 |
| `js/prototype.js` | 初期ガイドを共有する試作生成・全通常ホールドの削減検証 |
| `js/hazards.js` | 任意で使える消費ホールドの配置と無料ルートの維持 |
| `js/level-map.js` | スゴロクマップ・レベル解放・コース別の進行保存 |
| `js/input.js` | マウス・タッチ・スクロール・再開始 |
| `js/renderer.js` | プレイヤー・可動域・想定／実走パスの描画 |
| `js/main.js` | コース選択画面と描画ループの開始 |

`file://` で動く通常のdeferスクリプトを使用します。旧1肢固定コースと固定パターン検証ステージはありません。両コースとも同じ2点固定ルールです。

## テスト

```sh
node tests/routes.cjs
node tests/animations.cjs
node tests/prototype.cjs
node tests/poses.cjs
node tests/rules.cjs
node tests/level-map.cjs
node tests/input.cjs
node tests/hazards.cjs
```

既存・試作それぞれ20レベルの実入力クリア、固定ペアの維持、接触先、ホールド削減、キャンセル、実走パス、❤️の回収とスタミナを確認します。録画は明示的な依頼がある場合だけ行います。

Windowsでは次のスクリプトも使用できます。Node.jsがなければVS CodeのElectronを使います。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/test-routes.ps1
```

配置の調査には `node scripts/inspect-routes.cjs 1 3` を使用できます。

詳細は [ゲーム仕様](GAME_SPEC.md) と [生成手順](docs/course-generation.md) を参照してください。`docs/layout-study.md`、`docs/controll_test.md`、`docs/report_light.md` は過去の検討記録です。

姿勢制御の詳細と優先順は [docs/pose-control.md](docs/pose-control.md) を参照してください。

青ホールドの追加消費時はボディだけを280ms横に震わせ、各ホールド位置に青い「-1」を表示する。文字は❤️の「+2」と同じく1秒で30px上がりながら消える。確定前・保持継続では発火しない。Undo・再開始・マップ復帰で震えを解除する。論理姿勢・保持先には影響しない。

ステージマップの「デバッグモード」をオンにすると番号入力から任意のステージをプレイできる。通常の解放制限は維持し、デバッグで入ったステージはリトライ後もクリア進捗を保存しない。マップへ戻ると通常の次ステージ位置へ戻る。デバッグモードは永続保存しない。
