# iOS 同期診断の表示

旧Webキューは送信対象外として保持するが、設定の送信待ち表示がその旧件数を参照していた。iOSコピーの初期描画・同期通知・言語切替・ステージ状態表示を専用プレゼンターへ統一し、件数には新キューのfreshPendingだけを使う。旧キューは送信・消去・書換しない。Webの表示挙動は変更しない。

## 最終ビルド方針

診断表示はDebugビルド限定で、ゲーム内デバッグモードのON/OFFとは独立する。通信状態・実際のスコア送信待ち件数・プロフィール保留・安全なエラーコードをDebugで表示。通常Releaseは常に非表示で、旧フラグtrueや言語切替でも表示しない。
一時的なRelease確認用overrideはコード、Info.plist、Xcodeプロジェクトから削除した。ReleaseのネイティブpolicyはsyncStatusAllowed=false固定で、UI側もconfiguration=Debugを必須とする。通常のプロフィール編集・Firebase同期処理・エラー時のキュー保持を停止する変更ではない。
エラー表示は許可された安全なコードのみ。UID・トークン・URLや任意メッセージは表示しない。診断ファイルの収集は従来どおりDebug限定かつ明示起動指定が必要。新しいサーバー送信・Rules変更はない。

## 検証の境界

一時確認用Release 0.4.0/build8で、ユーザーがオンライン同期、スコア送信待ち0件、エラーなし、言語切替で差がないことを確認した。旧記録は消去していない。
自動テストでは旧6件・新0件、初期状態、同期成否、オフライン/復帰、旧ベストによる非更新の確認応答、言語切替、Debugとゲーム内モードの独立、Releaseの強制非表示、override削除を確認。最終通常Releaseのビルド・実機更新結果は下記を参照。

通常Release 0.4.0/build8のBUILD SUCCEEDEDと署名厳格検査、最終assets検査が合格。完成品Info.plistに一時Release overrideがないこと、同梱プレゼンターがDebug構成を必須とすることを確認。同じiPhone 13 Proへ上書きインストール・通常起動がいずれも終了コード0。アンインストールやキュー消去は行わず、ユーザーが最終実機画面での診断非表示、言語切替後も非表示、進行保持、プロフィール編集をすべて確認済み。
