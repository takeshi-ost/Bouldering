# スコア記録のメタデータ

各スコアに次の任意フィールドを追加する。比較順、ランキング参加条件、ボードキー、履歴の保存方式は変更しない。

| フィールド | 新規記録の値 | 旧記録・値不明 |
| --- | --- | --- |
| appVersion | クリア時の RELEASE_VERSION（現在0.4.1） | null |
| buildNumber | iOS同梱Info.plistのCFBundleVersionをネイティブから注入（現在文字列9） | null。Webでは捏造しない |
| platform | iOSラッパーはiOS、ブラウザはWeb | null |
| scoreSpecVersion | クリア時のCOURSE_VERSION（現在v1） | null |

COURSE_VERSIONは既に「コース生成・ゲームプレイ変更でスコア比較不能になる世代」と定義され、ボードキーにも使われている。この世代をそのまま明示フィールドに使い、独立の版カウンターは増設しない。アプリのパッチ更新では増加させない。旧レコードにversion:v1やv1ボードキーがあっても、欠損メタデータを現在の値で補わない。

新規クリアのcandidateへ一度だけ採録し、通常/prototypeのlocal best・Web保留キュー・iOS有効化後キューへ値を引き継ぐ。再起動、アップデート、遅延送信、Firestore直列化では現在版を再取得しない。Dailyのローカルクリア記録も同じ採録と読取を行うが、Dailyの送信経路は追加しない。
既存bestを維持する場合はそのbestのメタデータを保持する。サーバーが同等/良い記録を返す場合も返された記録に属するメタデータを使い、ローカルで同値bestを保持する際はその元データを保つ。比較関数や手数/時間の順序は変更しない。
読み取りでは欠損・不正型・長さ上限外をnullに正規化する。アプリ版64文字、ビルド番号32文字、プラットフォーム32文字、スコア仕様版32文字以内の文字列。既存データの一括埋め戻しはしない。iOSの旧Web保留キューは読み取り時にもディスクへ書き戻さず、元データを保持する。

## Firestore Rulesへの影響

変更前RulesはstageScoresのmoves/timeMs/updatedAt以外を許可しなかった。firestore.rulesに任意項目として型・長さ・値を検証し、文字列/null/欠損を許容する最小差分を追加した。旧クライアントと旧文書は引き続き許容する。本人限定・数値上限・改善時のみ更新の条件は維持する。
後続の明示承認後、本番Rules全文を取得・変更前控え保存・差分照合し、4項目の最小変更を公式コンソールで公開した。再読み込みで全文一致を確認。Rules反映時には既存文書の埋め戻し/削除や直接のスコア送信を行わず、その後のユーザー実プレイ経由の保存を下記のとおり確認した。エミュレーター実行は依存未導入のため未実施であり、コンソール公開成功・ローカルモック合格とは区別する。

## 検証

- score-metadata: iOS/Webの採録、Webビルド番号null、アプリ版更新でv1不変、オフライン後アップデートの旧値維持、メタデータ導入前キューnull、過去キュー保持。
- online-scores / firebase-client: 実クリアcandidate、保存/再読込、旧記録、改善/悪化/同値bestの値と版情報、Firestore直列化、読取互換。
- native-firebase / native-auto-sync: 本人認証・境界・旧キュー隔離・オフライン/再起動・重複抑止とメタデータ保持。
- native input / Daily / assets / build-policy: ネイティブ実クリア経路、Daily保存、同梱スクリプト、ReleaseデバッグOFFの回帰確認。

## 版と検証の境界

ユーザー指定によりソースを0.4.0 / build 8へ更新。COURSE_VERSIONとscoreSpecVersionはv1のまま。実機は検証済み0.3.14 / build 7であり、0.4.0のネイティブ実機ビルド・更新は行っていない。
0.4.0/8/iOS/v1、WebのbuildNumber=nullをソース設定・生成assetsとともに自動検証する。アップデート前0.3.14/7のキューは新しい0.4.0実行環境でも元のメタデータを保持するテストを含む。

## 実機での保存検証（0.3.14 / build 7）

署名済みRelease 0.3.14/build7をiPhone 13 Proへ上書きし、ユーザーが通常STAGE10を実プレイでクリア。公式Firebaseコンソールでv1_existing_10の本人用スコアを読み取り、appVersion=0.3.14、buildNumber=文字列7、platform=iOS、scoreSpecVersion=v1、moves=23、timeMs=20507、更新時刻2026-10-25 10:18:31 UTC+9を確認。同じ所有者のプロフィールはiOS接続テスト、到達ステージ11。
通常Releaseの診断収集は無効。iPhone内のローカル記録・キュー・認証UIDを直接取得していないため、ローカルとの完全数値照合・全キュー消化・更新前後UID一致を独立に確認したとは扱わない。サーバー保存4項目と同梱版の期待値の一致を確認した。
既存文書の埋め戻し・削除・架空スコア生成は行っていない。

## 同期診断修正後の版

現在のソースは0.4.1/build9、仕様世代はv1を維持。実機は診断Debug限定化まで最終確認済みの通常Release 0.4.0/build8。保存時の版番号とassets更新のためだけの実機再ビルドは行わない。
