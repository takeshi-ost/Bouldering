# 姿勢制御のロジックと優先順

確認日：2026-09-22。対象実装：`19aabb13ca6fe19c60522e7e5fabf1e3a5e86b02`。
本書は現在の実装を説明する。過去に検討した条件や今後の理想仕様とは区別する。

## 1. 全体の考え方

ホールドへの接触と固定長の骨格を保ちながら、人体らしい関節方向と、2Dラグドールらしい広がりを選ぶ。固定した胴体位置だけでは条件が衝突する場合、有効な操作の確定後に描画用の胴体位置も探索する。

「接触を維持できるか」「同じ胴体位置でどちらに曲げるか」「胴体をどこへ移すか」は、以下のように判定する。**すべての条件を一列の優先順位で処理しているわけではない。**

| 段階 | 優先順・選び方 |
|---|---|
| 接触・到達判定 | 到達距離、足先の高さ、高い足の角度条件をすべて満たす必要がある |
| 肘・膝の選択 | 固定長で成立する候補のうち、共通の重み付きコストが最小の候補を選ぶ |
| 胴体位置の選択 | 移動全区間で4接触を維持 → 違反数が少ない → 同数なら合計コストが低い |
| 表示 | 四肢を先に描き、胴体をその上に描く |

## 2. 必ず守る条件

以下は通常プレイ中の到達判定と、確定後の胴体調整に適用する。

| 項目 | 現在の条件 |
|---|---|
| 接触位置 | 確定後の姿勢調整では4つのホールド位置を変えない |
| 腕の長さ | 上腕50px＋前腕50px。肩から手まで最大100px |
| 脚の長さ | 太もも55px＋膝下55px。股関節から足まで最大110px |
| 骨の伸縮 | 姿勢を成立させるための伸縮・短縮をしない |
| 足先の上限 | 胴体の中点以下 |
| 股関節より高い足 | 膝内角150度以上で届く場合だけ許可。股関節～足先は約106.25～110px |
| 股関節と同じ高さ以下の足 | 上記150度条件は適用しない |
| 胴体調整の移動経路 | 始点と終点だけでなく、直線移動の途中も4肢が到達条件を満たす |

足の高さは画面の上下を基準にする。Y座標は下向きが正。胴体は幅40px、高さ72pxで、肩・股関節は中心から左右20px、上下36pxにある。

## 3. 肘・膝の候補を作る

肩または股関節と、手先または足先の間に、長さが等しい2本の骨を接続する。通常は左右の曲げ方向に相当する2つの関節候補が得られる。完全に伸びた場合は同じ位置になる。

付け根と末端がほぼ一致する場合は、付け根を中心とした円周上の16候補を評価する。肘を必ず真下、膝を必ず真上とする特別処理はない。

各肢の候補は、次節の共通コストが最小になるものを選ぶ。コストが完全に同じなら、画面上で高い候補を選ぶ。**この段階では違反数を先に比較しない。**

## 4. 共通の関節評価

コストは低いほどよい。候補を条件ごとに排除せず、以下を加算する。

| 評価項目 | コストへの寄与 | 意味 |
|---|---:|---|
| 内向き | 内向き距離 × 4 | 左肢は付け根より右、右肢は付け根より左に入るほど不利 |
| 胴体との重なり | 胴体内への深さ × 4 | 肘・膝が胴体内部に深く入るほど不利 |
| 外への広がり | 外向き距離 × −1 | 外に出るほど有利。内側では距離が負になり、追加の不利となる |
| 低い手に対する高い肘 | 肩を超える高さ × 0.75 | 手が肩と同じ高さ以下の場合だけ適用 |
| 折り畳んだ脚の膝の高さ | 腰から膝への下向き距離 × 折り畳み係数 × 0.5 | 膝が高いほど有利。腰より高ければ負のコストになる |
| 前フレームとの連続性 | 関節の相対位置の変化量 × 0.03 | ほぼ同評価の候補では直前の曲げ方を保ちやすくする |

内向き・重なりを強く嫌い、外への広がりを好む設計。ただし重みは順位ではなく、距離に掛ける係数なので、各条件の大小によって結果は変わる。

### 重なりの測り方

関節点が胴体の矩形内部にあるとき、最も近い辺までの距離を使う。外側・境界上なら0。上腕・前腕などの線分全体の重なりや、四肢同士の交差は直接評価していない。

### 折り畳み係数

股関節～足先の距離を `d`、膝内角120度に相当する距離を `L ≒ 95.26px` とすると、係数は次のとおり。

`fold = clamp((L − d) / (L × 0.2), 0, 1)`

95.26px以上では0、近づくほど増え、約76.21px以下で1になる。「120度を境に膝を上にする候補だけを残す」処理ではない。

### 条件が衝突した場合

- 近い手で「外向きの肘」と「肩以下の肘」が両立しなければ、肩を超える肘を選ぶ場合がある。
- 膝を高くすると大きな内股になる場合は、膝を低くして外へ開く候補を選ぶ場合がある。
- 骨の長さと接触位置によっては、両候補とも内向き・重なりを避けられない。その場合もコストが小さい方を選ぶ。
- 連続性は小さなコストであり、曲げ方向の反転を完全に防ぐものではない。

## 5. 四肢固定後の胴体位置調整

有効な操作を確定したとき、元の胴体位置を基準に候補を探索する。4接触がそろっていない、または元の位置が到達条件を満たさない場合は移動しない。

各胴体候補で4肢の関節を再計算し、同じ関節評価を合計する。この探索では前フレームの関節履歴を渡さないため、連続性コストは0になる。実際の描画時には履歴を使うため、僅差の候補で探索時と異なる曲げ方を選ぶ可能性がある。

### 第1優先：移動中も4接触を保つ

探索する胴体中心は `x=25～375`、`y=80～ステージ高さ−40` に収める。これはステージ内の制限であり、現在表示中のカメラ範囲に限定するものではない。

元の位置から候補位置まで、両手と両足それぞれの到達区間を解析する。途中で条件を破る場合は最初の境界まで移動量を短くする。高い足の禁止領域を飛び越えて終点だけ成立する移動は採用しない。

### 第2優先：違反数を減らす

各肢で以下の値が**1を超える項目**を1件として数え、4肢分を合計する。

| 違反項目 | 数える条件 |
|---|---|
| 重なり | 関節が胴体内部に入る深さ > 1px |
| 内向き | 付け根から内側への距離 > 1px |
| 高い肘 | 手が肩以下、かつ肘が肩を超える高さ > 1px |
| 低い折り畳み膝 | 腰より低い距離 × 折り畳み係数 > 1 |

同じ関節が内向きかつ重なっていれば2件。最後の項目は係数を掛けた値であり、単純な「腰より1px低い」とは異なる。

違反数が減る候補は、合計コストが増えていても優先する。これは「少数の大きな違反を浅くする」より「違反する項目を減らす」を優先する仕様である。

### 第3優先：同数なら合計コストを下げる

`胴体候補のコスト = 4肢の関節コスト合計 + 元の胴体位置からの移動距離 × 0.05`

現在の最良候補より0.05を超えてコストが下がる場合だけ置き換える。違反数が増える候補は採用しない。最初の最良候補は元の位置なので、改善が見つからなければ動かない。

### 探索範囲と限界

最初に32方向×7距離（4、8、16、32、64、128、220px）を調べる。その後、最良位置の周囲を半径8、4、2、0.5pxの順に各16方向で調べる。最大288候補で、元の位置からの移動経路を毎回確認する。

有限の候補を調べる探索であり、全領域の最適解や、満たせる条件数の最大化を保証するものではない。曲がった経路でしか到達できない位置も対象外。

## 6. 動かし方とゲーム状態

採用した位置へ240msで移動する。直線上を `1 − (1 − t)^3` のイージングで進み、移動中も関節は固定長で再計算する。骨や関節点を補間して短縮する処理はない。

調整は描画用の胴体位置に適用する。ゲーム本体の `body`、確定座標、吸着先、実走パス、手数、勝敗は変更しない。調整後の位置は次の操作まで表示し、次の操作開始時に解除する。したがって、調整位置を次の操作の論理的な始点として引き継ぐ実装ではない。

キャンセルや接触位置が変わらない操作では、新たな調整を始めない。初期配置を常時最適化する処理でもない。移動全区間の到達条件は保証対象だが、途中の全フレームで姿勢コストが単調に改善する保証はない。

## 7. 描画と別の演出

- 手足を先に、胴体をその後に描く。胴体に重なる四肢は隠れる。折り畳んだ脚だけを手前に出す例外はない。
- 未吸着の肢は下へ垂れ、少し揺れる末端を使って関節を計算する。
- 登頂後は別の演出へ切り替える。両手をゴールに保ち、脚はホールドから離して下へ伸ばし、体を揺らす。この演出には「4接触を維持する」を適用しない。
