# 英語文言の意味合わせ監査（0.4.60）

監査日: 2026-11-04。基準は未公開の `0.4.60`、コミット `4f63bdf` の日本語です。

## 対象と方針

`js/text-ja.js` の268項目と `js/text-dev-ja.js` の26項目を、英語、実際の表示箇所、差し込み値の意味と突き合わせました。キーの存在だけでなく、条件、数値、例外、用語、段落、削除された説明の残存を確認しています。最新の日本語を正とし、日本語本文、画像、ゲームの挙動、保存形式、バージョンはこの文言修正では変更していません。

文言の変更先は `js/text-en.js` です。あわせて `js/text-dev-ja.js` の説明コメント、詳細説明のテスト3本（`help-owner-copy.cjs`、`help-document.cjs`、`help-layout.cjs`）と本書を更新しました。既存の英語54項目を修正し、保守・デバッグ用の26項目を英語辞書に追加しました。英語辞書は日本語2辞書の計294項目をすべてカバーします。既存の単数形5項目は維持し、キャラクター配色の「1 color」と削除件数の「1 record」を追加しました。

## 大きな差異と修正

### 詳細説明

- 英語で欠落していた「足は手より高く置けない」「ゴールホールド」「チョークバッグの使用」「次ステージの解放・クリア済みステージの再プレイ」「失敗時のライフ消費」を追加。
- 日本語で削除済みの説明が英語だけに残っていた9項目を、同じ空文字に統一。
  - `help.rules.tutorial`
  - `help.holds.chalkLabel` / `help.holds.chalk`
  - `help.map.records` / `help.map.rewards` / `help.map.lives`
  - `help.daily.attempts` / `help.daily.rewards`
  - `help.settings.navigation`
- スタミナの旧説明から「毎回必ず1消費」「0到達と同時のゴールは成功」「残量の次ステージへの持ち越し」を削除。現在の日本語の「ムーブごとに消費し、0になる前にゴール」に合わせた。
- Undoの旧説明からスタミナ回復、連続Undo、次ムーブ後の再利用に関する補足を削除し、直前の1ムーブだけ戻せる説明に統一。
- スクロールから事前のルート計画、通常ホールドから開始・ゴールの色、尖ホールドから再把持や手足の入れ替え、ハートから取得回数とUndo後の回復保持に関する旧補足を削除。
- ホールドの「Heart」見出しを現在の「スタミナ+2」に対応する「Stamina +2」に変更。チョークバッグの説明は現在の日本語と同じマップ節へ移動。
- デイリーは、その日のお題と「ライフを消費しない／チョークバッグは使えない」を同じ2段落構造に統一。過去・未来の日付制約、再プレイ、報酬・ストリークの旧説明は追加しない。
- 設定は音楽・効果音、音量、言語、場所に応じた移動先を同じ本文にまとめ、日本語の改行を維持。引用する英語ボタン名は実際の「Give Up」「Title Screen」「Randomize」「Confirm」「Back」と一致。
- キャラクターの変更が影響しない対象を、旧英語の狭い「reach」ではなく、日本語の「登る力」に合わせた「climbing ability」に修正。

### STAGE 0 と初出説明

英語辞書にそのまま入っていた日本語9項目を翻訳しました。スワイプと指を離す操作、自由に動く2本の手足、足の高さ制限、スタミナが切れる前の両手ゴール、両足の固定、歯車メニューの説明を省略していません。大きなホールドのタイトルと本文も英語化しました。最新の日本語にない操作や条件は追加していません。

### その他の文言

- 未送信記録保護に伴う通信停止を、従来の単なる一時停止表現から合わせた。
- ルート表示を使った記録、次の検証用ステージから有効になる補正値、進行・正式記録への非保存を明確化。
- デバッグの生成に「乱数」、再生成に「別seed」を明示し、要求方針と分類の一致・不一致を省略しない表現にした。
- 尖ホールドの説明は「新しいホールド」そのものではなく、新たに手足を固定することが追加消費の条件だと分かる表現にした。
- 頭に手を「添える」を「near」から「on」に、身体の塗り分けを「Body Color Sections」に修正。
- 旧版の引き継ぎファイルに関する英語固有の「progress generation」を取り除き、同じUIDを確認する処理を明示。
- 英語でも日本語になっていた削除警告、削除途中の復旧、デバッグの操作・読み上げを翻訳。削除の対象、取り消せないこと、新しいユーザーは自動作成されないことを省略していない。

## 意図的に維持した相違・対象外

- 言語選択肢の「日本語」「English」は、その言語自身の表記を維持。これは未翻訳ではありません。
- 日付は英語でも既存の数値表記を維持。曜日名と年の配置は英語向けですが、値と日付の意味は変わりません。`TAP`、`STAGE`、`UID`、`DEBUG`、`BGM`、難易度などの既存表記も維持。
- ステージ開始画面の一部の日本語読み上げには、チョークバッグ画像に対して旧名称の「ハート」が残っています。英語の「Hearts」もその日本語に合わせたままです。日本語と英語で別の名称にしないため、今回英語だけを「Chalk Bags」に変更していません。マップ所持数・報酬・詳細説明は両言語ともチョークバッグです。
- `assets/help-character-editor-v1.jpg` には「ボディの塗り分け」「おまかせ」が画像内に描かれています。この画像は変更せず、英語でも同じ画像を使用します。英語本文と実際のキャラクター編集画面の文言は翻訳されています。他の3枚の説明用JPG（デイリー、マップ、スタミナ・ライフ）は確認時に日本語文字を含んでいませんでした。
- 削除済みの日本語説明に以前書かれていたゲームの細則は、実装に存在する場合でも英語だけに再掲載していません。今回の基準は現行の日本語であり、ルール変更や日本語本文の訂正ではありません。
- プレイヤー入力名、UID、数値、診断JSON内の技術識別子、保存キーは翻訳しません。`text-ja.js` は本文もコメントも変更していません。`text-dev-ja.js` は英語がないことを前提とした古い説明コメントだけを更新し、日本語本文は変更していません。
- チュートリアルと初出ホールド説明の言語属性・言語切替時の更新は、文言辞書以外の変更箇所です。この監査ではハードコードされた `lang="ja"` と初期化時に固定された文言を検出し、別途修正対象として報告しました。
